title: PostgreSQL-Datenbanken
summary: Eine eigene PostgreSQL-Datenbank für Ihr Projekt, um mit SQL, R, Python oder einem GIS zu arbeiten.

---

Für Teams, die direkten SQL-Zugriff benötigen, aus R, Python oder einem
GIS wie QGIS: eine PostgreSQL-Datenbank auf einem eigenen Server für Ihr
Projekt, betreut gemeinsam mit der DIT. Jedes Projekt durchläuft vor der
Eröffnung eine Sicherheitsprüfung.

Eine PostgreSQL-Datenbank kann auch eine NocoDB-Eingabeoberfläche
erhalten: Ihr Team erfasst die Daten in NocoDB, und Sie werten sie mit SQL
aus.

### Inbegriffen

- Ein eigener Server für Ihr Projekt, auf der Infrastruktur der
  Universität.
- Sicherungen, Aktualisierungen und Sicherheit.
- Die Einrichtung der Datenbank und der Zugänge Ihres Teams.

### Nicht inbegriffen

- Ihre Abfragen, Skripte und Auswertungsanwendungen.
- Die Erfassung der Daten, ausser mit einer angeschlossenen
  NocoDB-Oberfläche.
