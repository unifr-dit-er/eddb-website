title: Bases PostgreSQL
summary: Une base PostgreSQL dédiée à votre projet, pour travailler en SQL, avec R, Python ou un SIG.
order: 2
---

Pour les équipes qui ont besoin d’un accès direct en SQL, depuis R, Python
ou un SIG comme QGIS : une base PostgreSQL sur un serveur dédié à votre
projet, administré avec la DIT. Chaque projet fait l’objet d’une
validation de sécurité avant son ouverture.

Une base PostgreSQL peut aussi recevoir une interface de saisie NocoDB :
votre équipe saisit ses données dans NocoDB, et vous les analysez en SQL.

### Ce qui est compris

- Un serveur dédié à votre projet, sur l’infrastructure de l’Université.
- Les sauvegardes, les mises à jour et la sécurité.
- La création de la base et des accès de votre équipe.

### Ce qui ne l’est pas

- Vos requêtes, vos scripts et vos applications d’analyse.
- La saisie des données, sauf à y brancher une interface NocoDB.
