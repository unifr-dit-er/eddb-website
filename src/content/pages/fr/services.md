EDDB propose trois services, qui se combinent selon les besoins de votre
projet : une base de données pour saisir et organiser vos données, et, si
vous le souhaitez, une vitrine pour les publier.

## Bases NocoDB

[NocoDB](https://nocodb.com) est le cœur de l’offre : une base de données
relationnelle en ligne, qui se manie comme un tableur, sans programmation.

- Tables, relations entre les tables, pièces jointes (images, PDF),
  vues filtrées et formulaires de saisie.
- Un accès pour chaque membre de l’équipe, avec son rôle : lecture,
  saisie ou administration. Des partenaires extérieurs à l’Université
  peuvent être invités.
- Une API, pour travailler les données avec R ou Python, ou pour
  alimenter une vitrine.
- Un export de vos données en CSV, à tout moment.

### EDDBs, pour les données sensibles

Une seconde instance, accessible seulement depuis le réseau de
l’Université, accueille les projets dont les données sont sensibles.

## Bases PostgreSQL

Pour les équipes qui ont besoin d’un accès direct en SQL, depuis R, Python
ou un SIG comme QGIS : une base PostgreSQL sur un serveur dédié à votre
projet, administré avec la DIT (mises à jour, sauvegardes). Chaque projet
fait l’objet d’une validation de sécurité avant son ouverture.

Une base PostgreSQL peut aussi recevoir une interface de saisie NocoDB :
votre équipe saisit ses données dans NocoDB, et vous les analysez en SQL.

## Vitrines publiques

Une vitrine est un site de consultation développé par la DIT-ER pour
publier tout ou partie de vos données. Elle lit directement votre base :
ce que votre équipe saisit apparaît en ligne, sans export. Vous choisissez
les champs publiés ; le reste demeure privé.

Trois niveaux, sur devis :

- **Simple** : liste, recherche, fiche détaillée, présentation standard,
  une ou deux tables.
- **Intermédiaire** : recherche avancée, liens entre les fiches,
  présentation personnalisée, plusieurs tables.
- **Complète** : interopérabilité (IIIF), cartographie, plusieurs
  langues, présentation sur mesure.

Une vitrine est servie sous eddb.unifr.ch ou à sa propre adresse, comme
[datacant.unifr.ch](https://datacant.unifr.ch).

### Sans vitrine : l’accès public

Une base NocoDB peut aussi être ouverte en lecture à tout le monde. Les
données gardent alors l’apparence de l’interface NocoDB : une solution
rapide quand une adresse publique suffit.

## Ce qui est compris

- L’hébergement sur les serveurs de l’Université.
- Les sauvegardes, les mises à jour et la sécurité.
- L’accompagnement : modélisation de vos données, reprise de vos données
  existantes (tableur, CSV, ancienne base), formation de votre équipe.

## Ce qui ne l’est pas

- La saisie des données, qui reste l’affaire de votre équipe.
- La page de présentation de votre projet sur le site de l’Université :
  elle relève de votre département.
