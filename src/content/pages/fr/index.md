EDDB (*Educational Databases*) est un service de la DIT-ER, à l’Université
de Fribourg. Il accompagne les enseignant·e·s, les chercheuses et les
chercheurs qui ont besoin d’une base de données pour leur projet, de la
modélisation des données à leur publication.

## Ce que nous proposons

### Bases NocoDB

Une base de données en ligne, avec une interface de saisie aussi simple
qu’un tableur : tables, relations, pièces jointes et droits pour chaque
membre de l’équipe. Une instance sécurisée, en intranet, accueille les
données sensibles.

### Bases PostgreSQL

Pour les équipes qui travaillent en SQL, avec R, Python ou des outils SIG :
une base PostgreSQL dédiée, administrée avec la DIT.

### Vitrines publiques

Un site de consultation pour publier tout ou partie de vos données :
recherche, fiches détaillées, plusieurs langues.

## Science ouverte

EDDB vous aide à rendre vos données FAIR, par exemple par une
synchronisation avec la plateforme nationale DaSCH ou par un dépôt dans
OLOS.
